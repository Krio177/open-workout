# v1.14 Feature Pack: 1RM, Export, Warmup Sets, Exercise History

## 1. 1RM Display on Set Cards

**What:** Show calculated 1RM estimate on each set row during workout.

**UI:** After the reps "x" label, a small grey text: `~95kg 1RM`. Only shown when:
- `weight > 0` and `reps > 0` and `reps < 37`
- Set is not marked as warmup

**Formula:** Brzycki (already in server.js): `weight × (36 / (37 - reps))`

**Implementation:** Pure frontend calculation — no backend changes needed. Computed inline in the set template.

## 2. JSON Data Export Endpoint

**Endpoint:** `GET /api/export?from=YYYY-MM-DD&to=YYYY-MM-DD`

Both date params optional. No dates = export all finished sessions.

**Response:**
```json
{
  "exported_at": "2026-05-07T18:00:00Z",
  "filter": { "from": "2026-04-01", "to": "2026-05-07" },
  "sessions": [
    {
      "id": 1,
      "workout_id": "chest-day",
      "workout_name": "Mell nap",
      "started_at": "2026-05-01T10:00:00Z",
      "finished_at": "2026-05-01T11:15:00Z",
      "total_weight": 4520.00,
      "sets": [
        {
          "exercise_name": "Fekvenyomas",
          "equipment": "barbell",
          "set_number": 1,
          "weight": 80,
          "reps": 8,
          "is_warmup": false,
          "completed_at": "2026-05-01T10:05:00Z"
        }
      ]
    }
  ]
}
```

**Query:** Join `workout_sessions` + `exercise_sets`, filter by `finished_at` date range, order by `started_at DESC`. Workout name resolved from in-memory workout definitions map.

## 3. Warmup Set Marking

### Database
- Add `is_warmup BOOLEAN DEFAULT false` column to `exercise_sets` table.

### Backend
- `POST /api/sessions/:id/sets` — accept `is_warmup` field. If `is_warmup=true`, skip PR check.
- `PUT /api/sessions/:id/finish` — exclude warmup sets from `total_weight` calculation.

### Frontend (workout.html)
- Each set in `allSets` gets an `isWarmup: false` property.
- Before the set number label, a small toggle button:
  - Default state: hidden/subtle, shows set number "S1"
  - Toggled on: shows "W" in amber/orange, set row gets a distinct muted style
- Toggle only works when `!set.done`.
- When completing a warmup set, send `is_warmup: true` in POST body.
- Warmup sets do NOT count toward `allCurrentSetsDone` / `isExerciseDone` checks.
- 1RM display hidden on warmup sets.

### Visual
- Warmup row: lower opacity (opacity-60), amber "W" badge instead of "S1".
- Done warmup: amber-tinted instead of emerald.

## 4. Exercise History Mini Chart

### Backend
**Endpoint:** `GET /api/exercises/:name/history?limit=10`

**Query:** For the given exercise name, find the last N finished sessions that contain sets for this exercise. For each session, return the max weight used (excluding warmup sets).

**Response:**
```json
{
  "exercise_name": "Fekvenyomas",
  "history": [
    { "date": "2026-04-15", "max_weight": 75, "max_reps": 8, "one_rm": 94.7 },
    { "date": "2026-04-22", "max_weight": 80, "max_reps": 6, "one_rm": 92.9 }
  ]
}
```

### Frontend (workout.html)
- Below the exercise header card, a collapsible section.
- Toggle button: small "Elozmeny" (History) text link.
- Chart.js line chart (compact, ~120px height):
  - X axis: dates
  - Y axis: max weight (kg)
  - Workout color as line color
  - Tooltip shows: date, max weight, 1RM
- Data fetched once per exercise switch, cached in `exerciseHistory` object.
- If no history (new exercise), section hidden.
